## 📌 Описание задания
Добавить в проект базу данных MySQL и веб-интерфейс Adminer, подключиться к базе из PHP через PDO и хранить данные формы в таблице вместо файла.

**Вариант 18: «Заявка на ремонт техники»**. Заявки сохраняются в таблицу `repair_requests` и выводятся на главной странице.

Результат доступен по адресу [http://localhost:8080](http://localhost:8080).

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/jkkjjkjkjkjk/web_labs
   cd web_labs/lab5/nginx-lab
   ```
2. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
3. Подождать около 30 секунд, пока MySQL создаст базу при первом запуске.
4. Открыть в браузере:
   - форма: [http://localhost:8080/form.html](http://localhost:8080/form.html)
   - список заявок: [http://localhost:8080/index.php](http://localhost:8080/index.php)
   - Adminer: [http://localhost:8081](http://localhost:8081)

Данные для входа в Adminer:

| Параметр | Значение |
| --- | --- |
| Система | MySQL |
| Сервер | `db` |
| Пользователь | `lab5_user` |
| Пароль | `lab5_pass` |
| База данных | `lab5_db` |

## 📂 Содержимое проекта

- `Dockerfile`: образ PHP-FPM с расширениями `pdo` и `pdo_mysql`
- `docker-compose.yml`: сервисы `web` (Nginx), `php`, `db` (MySQL 8), `adminer`
- `nginx/default.conf`: конфигурация Nginx
- `www/db.php`: подключение к базе через PDO, создание таблицы при первом запуске
- `www/RepairRequest.php`: класс для работы с таблицей (добавление, получение, обновление, удаление)
- `www/form.html`: форма заявки
- `www/process.php`: проверка данных и сохранение в базу
- `www/index.php`: вывод заявок из базы
- `screenshots/`: скриншоты работы

---

## 🧩 Реализация

- **Подключение.** `db.php` создаёт соединение PDO с режимом исключений (`ERRMODE_EXCEPTION`) и кодировкой `utf8mb4`. Если подключиться не удалось, выводится сообщение об ошибке.
- **Таблица `repair_requests`:** `id` (автоинкремент), `username`, `model`, `service`, `warranty` (`TINYINT`), `term`.
- **Класс `RepairRequest`.** Все запросы выполняются через подготовленные выражения (`prepare` и `execute`), что защищает от SQL-инъекций.
- **process.php.** Проверяет поля формы (имя, модель, услуга и срок из списка допустимых значений) и добавляет запись в базу. При ошибках показывает их на главной странице.
- **index.php.** Выводит таблицу с сохранёнными заявками, все значения экранируются через `htmlspecialchars`.
