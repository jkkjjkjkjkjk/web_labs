## 📌 Описание задания
Подключить менеджер зависимостей Composer, установить HTTP-клиент Guzzle и получать данные из внешнего API. Дополнительно вывести информацию о пользователе (IP, user agent, время). Проект развивает лабораторную работу №3.

**Вариант 18: «Заявка на ремонт техники»**. Внешний API:
`https://dummyjson.com/products/category/smartphones` (список смартфонов).

Результат доступен по адресу [http://localhost:8080](http://localhost:8080).

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/jkkjjkjkjkjk/web_labs
   cd web_labs/lab4/nginx-lab
   ```
2. Установить зависимости Composer (нужен Composer и PHP 8.2+):
   ```bash
   cd www
   composer install
   cd ..
   ```
   Если Composer не установлен, можно использовать Docker:
   ```bash
   docker run --rm -v "%cd%/www:/app" composer install
   ```
3. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
4. Открыть форму [http://localhost:8080/form.html](http://localhost:8080/form.html), отправить заявку. После отправки откроется `index.php` с таблицей данных из API.

## 📂 Содержимое проекта

- `docker-compose.yml`, `nginx/default.conf`: окружение (Nginx + PHP-FPM)
- `www/composer.json`: зависимости (`guzzlehttp/guzzle`)
- `www/ApiClient.php`: класс для запросов к API через Guzzle
- `www/UserInfo.php`: класс с информацией о пользователе
- `www/api.php`: JSON-эндпоинт для кнопки «Обновить данные»
- `www/form.html`: форма заявки
- `www/process.php`: проверка данных, сохранение, запрос к API
- `www/index.php`: вывод данных сессии, куки, информации о пользователе и таблицы из API
- `screenshots/`: скриншоты работы

Папка `vendor/` и файл кеша `api_cache.json` в репозиторий не попадают.

## 🧩 Реализация

- **ApiClient.** Класс использует Guzzle с таймаутом 5 секунд. Любая ошибка (сеть, статус 4xx/5xx, некорректный JSON) превращается в сообщение об ошибке, поэтому сохранение заявки не ломается, если API недоступно.
- **UserInfo.** Возвращает IP-адрес (`REMOTE_ADDR`), `User-Agent` и текущее время.
- **process.php.** После проверки данных сохраняет заявку (сессия, файл, куки), запрашивает API и кладёт ответ в сессию. Дополнительно ставится кука `last_submission` со временем последней отправки (на 1 час).
- **index.php.** Показывает данные заявки, куки, блок «Информация о пользователе» и таблицу смартфонов (название, бренд, цена).

### ⭐ Штрафное задание
- **Кеширование** ответа API в файле `api_cache.json` на 5 минут (ошибки в кеш не записываются).
- **Кнопка «Обновить данные»**: делает запрос через `fetch` к `api.php` без перезагрузки страницы, обновляя таблицу и принудительно обновляя кеш.
- **Обработка ошибок API:** сообщение об ошибке выводится пользователю на странице.
