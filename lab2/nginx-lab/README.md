## 📌 Описание задания
Подключить PHP-FPM к веб-серверу Nginx в Docker, проверить работу PHP страницей с `phpinfo()` и создать HTML-форму, данные которой обрабатываются на JavaScript без перезагрузки страницы.

**Вариант 18: «Заявка на ремонт техники»**. Поля формы:
- имя (текстовое поле);
- модель устройства (текстовое поле);
- услуга (выпадающий список);
- «Гарантия есть» (чекбокс);
- «Срок ремонта» (радиокнопки).

Результат доступен по адресу [http://localhost:8080](http://localhost:8080).

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/jkkjjkjkjkjk/web_labs
   cd web_labs/lab2/nginx-lab
   ```
2. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
3. Открыть в браузере:
   - страница PHP: [http://localhost:8080/index.php](http://localhost:8080/index.php)
   - форма: [http://localhost:8080/form.html](http://localhost:8080/form.html)
4. Остановить контейнеры:
   ```bash
   docker compose down
   ```

## 📂 Содержимое проекта

- `docker-compose.yml`: сервисы `web` (Nginx) и `php` (PHP-FPM 8.2), зависимость `depends_on`
- `nginx/default.conf`: конфигурация Nginx, передающая `.php` файлы в PHP-FPM (`php:9000`)
- `www/index.php`: страница с `phpinfo()`
- `www/form.html`: форма с обработкой на JavaScript
- `screenshots/`: скриншоты работы

---

## 🧩 Реализация

- Форма обрабатывается через `addEventListener("submit", ...)` с `preventDefault()`, страница не перезагружается.
- Результат выводится в блок `div#result`.
- Если поля не заполнены, они подсвечиваются красным и показывается предупреждение.

### ⭐ Штрафное задание
- **CSS:** форма по центру страницы, границы и фон полей, стилизованная кнопка.
- **Анимации:** плавное появление формы при загрузке (fade-in) и плавная смена цвета кнопки при наведении (`transition`).
- **Напоминание:** если 15 секунд нет активности, показывается сообщение «Пожалуйста, заполните форму!» и подсвечиваются пустые поля.
