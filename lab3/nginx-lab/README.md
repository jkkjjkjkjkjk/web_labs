## 📌 Описание задания
Реализовать серверную обработку формы на PHP: получить данные методом POST, проверить их, сохранить в сессии и в файле, вывести сохранённые данные. Форма отправляется на сервер, а JavaScript используется только для предупреждения (`alert`) перед отправкой.

**Вариант 18: «Заявка на ремонт техники»** (имя, модель, услуга, гарантия, срок ремонта).

Результат доступен по адресу [http://localhost:8080/form.html](http://localhost:8080/form.html).

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/jkkjjkjkjkjk/web_labs
   cd web_labs/lab3/nginx-lab
   ```
2. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
3. Открыть в браузере:
   - форма: [http://localhost:8080/form.html](http://localhost:8080/form.html)
   - главная: [http://localhost:8080/index.php](http://localhost:8080/index.php)
   - все сохранённые данные: [http://localhost:8080/view.php](http://localhost:8080/view.php)

## 📂 Содержимое проекта

- `docker-compose.yml`: сервисы Nginx и PHP-FPM
- `nginx/default.conf`: конфигурация Nginx
- `www/form.html`: форма (JS показывает только `alert`, затем форма уходит на сервер)
- `www/process.php`: обработка POST-запроса, проверка данных, сохранение
- `www/index.php`: вывод ошибок, данных из сессии и из куки
- `www/view.php`: вывод всех записей из файла
- `www/data.txt`: файл с заявками (создаётся автоматически, в репозиторий не попадает)
- `screenshots/`: скриншоты работы

---

## 🧩 Реализация

1. **Получение данных.** `process.php` принимает только POST, остальные запросы перенаправляет на форму.
2. **Проверка корректности:**
   - имя и модель не должны быть пустыми;
   - услуга и срок ремонта должны входить в разрешённый список значений.
   
   При ошибках пользователь возвращается на `index.php` и видит список ошибок.
3. **Сессия.** Данные заявки сохраняются в `$_SESSION` и выводятся на главной странице.
4. **Файл.** Каждая заявка дописывается в `data.txt` в формате `имя;модель;услуга;гарантия;срок` (с блокировкой `LOCK_EX`). Служебные символы `;` и переводы строк из значений удаляются.
5. **Просмотр.** `view.php` читает файл и выводит все записи, значения экранируются через `htmlspecialchars`.

### ⭐ Штрафное задание
Использование **cookies**: после успешной отправки в куки на 30 дней сохраняются последнее имя и последняя модель (`last_username`, `last_model`). Они выводятся на главной странице отдельным блоком.
